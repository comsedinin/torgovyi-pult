# Торговый пульт

Кликабельный прототип CRM для продавца на Wildberries и Ozon: воронка оптовых сделок, клиенты, цены с учётом комиссии и маржи, мониторинг конкурентов и автоматизации.

Сайт: https://comsedinin.github.io/torgovyi-pult/

Все компании, товары и цифры вымышлены. Изменения сохраняются только в браузере зрителя, кнопка «Сбросить демо-данные» возвращает исходное состояние.

Один файл `index.html` без сборки: HTML, CSS и JavaScript внутри, шрифт Inter с Google Fonts.
